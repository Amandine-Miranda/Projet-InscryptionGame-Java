# 🃏 Projet Inscryption Game Java

> Recréation du célèbre jeu **Inscryption** en **Java**, jouable directement dans la console.
>
> Ce projet a été réalisé dans le cadre de l'apprentissage de la programmation orientée objet et vise à reproduire les principales mécaniques du jeu de cartes roguelike d'horreur développé par Daniel Mullins.

---

## 📖 À propos du projet

Inscryption est un jeu de cartes stratégique mêlant deck-building, gestion de ressources et combats tactiques.

Cette version propose une adaptation console développée en Java, avec une architecture orientée objet permettant de gérer les cartes, les effets, le plateau de jeu et les différentes phases d'un combat.

---

## ✨ Fonctionnalités

### 🎴 Gestion des cartes

* Création de différents types de cartes
* Statistiques propres à chaque carte
* Points de vie et puissance d'attaque
* Gestion des capacités spéciales

### ⚔️ Système de combat

* Placement des cartes sur le plateau
* Résolution automatique des attaques
* Gestion des dégâts
* Destruction des cartes éliminées

### 🎮 Déroulement de partie

* Gestion des tours
* Interactions entre les cartes
* Conditions de victoire et de défaite

### 🧱 Architecture orientée objet

* Héritage
* Polymorphisme
* Encapsulation
* Utilisation d'UML pour la conception

---

## 🚀 Installation

### Prérequis

* Java JDK 17 ou supérieur
* Un IDE Java (IntelliJ IDEA, Eclipse, NetBeans...)

### Cloner le dépôt

```bash
git clone https://github.com/Amandine-Miranda/Projet-InscryptionGame-Java.git
cd Projet-InscryptionGame-Java
```

### Lancer le projet

Ouvrir le projet dans votre IDE puis exécuter la classe contenant la méthode :

```java
public static void main(String[] args)
```
